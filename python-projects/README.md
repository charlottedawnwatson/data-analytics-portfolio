# Ultra Marathon Data Analysis

## Project Overview

This project analyses ultra-marathon race results using Python, Pandas, NumPy, and Matplotlib. It demonstrates data cleaning, transformation, exploratory data analysis, and visualisation using a real-world race results dataset.

The notebook cleans and standardises race data, engineers new features such as athlete age and speed, filters the dataset, and produces a visual comparison of race speed by gender.

## Dataset

The original dataset linked below was used for the analysis, while the data file itself is not included in this repository as the file was too large to uplaod.
Data Source: https://www.kaggle.com/datasets/aiaiaidavid/the-big-dataset-of-ultra-marathon-running


## Project Workflow

### 1. Data loading and imports

The notebook loads the dataset into a Pandas DataFrame and imports the libraries needed for analysis.

### 2. Column standardisation and duplicate removal

Column names are renamed to simpler labels, unnecessary columns are removed, and duplicate records are dropped.

### 3. Age feature engineering

The athlete age category is cleaned and converted into a usable numeric age field, with an additional flag for under-age categories.

### 4. Missing values and distance filtering

Rows with missing gender values are removed, and the dataset is filtered to keep only race distances measured in kilometres.

### 5. Time parsing and speed calculation

Performance times are converted into timedelta values, total hours are calculated, and athlete speed is derived from distance divided by time.

### 6. Race stage parsing and completed-race subset

Race stage values are extracted where relevant, and a completed-race subset is created for analysis.

### 7. Final filtering and summary

A small number of outlier or unwanted race records are removed, and summary statistics are generated by athlete gender.

### 8. Visualisation

A scatter plot is created to compare race distance and speed for male and female athletes.
